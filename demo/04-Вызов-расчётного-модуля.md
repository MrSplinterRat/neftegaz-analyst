# Сценарий 4. Вызов расчётного модуля

**Что проверяем:** Агент сам вызывает расчётный модуль, возвращает прогноз с доверительным интервалом.

---

### Запрос

> Спрогнозируй цену Brent на 3 месяца и оцени диапазон при сокращении добычи на 1.5 млн барр./сут

### Ответ агента

Прогноз цены Brent и диапазон при сокращении добычи на 1.5 млн барр./сут.

Тезис о текущей цене и горизонте прогноза:
- Последняя известная цена Brent составляет 92.70 долл./барр. [Расчёт: ARIMA(1, 1, 1) + сценарий предложения, горизонт 90 дн.]
- Горизонт прогноза составляет 90 дн. [Расчёт: ARIMA(1, 1, 1) + сценарий предложения, горизонт 90 дн.]

Тезис о прогнозе цены и сценарии предложения:
- Прогноз на конец горизонта составляет 105.71 долл./барр. [Расчёт: ARIMA(1, 1, 1) + сценарий предложения, горизонт 90 дн.]
- Сценарий прогноза включает сокращение предложения на 1.50 млн барр./сут (эластичность 10% на 1 млн барр./сут). [Расчёт: ARIMA(1, 1, 1) + сценарий предложения, горизонт 90 дн.]

Тезис о доверительном интервале и неопределенности:
- 95% доверительный интервал составляет 73.04 — 138.39 долл./барр. [Расчёт: ARIMA(1, 1, 1) + сценарий предложения, горизонт 90 дн.]
- При росте горизонта неопределенность расширяется: 95% band widens from 8.50 to 65.35 USD/bbl as the horizon grows — uncertainty scales with the square root of time, so a distant point estimate carries far less information than a near one. [Расчёт: ARIMA(1, 1, 1) + сценарий предложения, горизонт 90 дн.]
- Residual sigma составляет 2.89 USD/bbl. [Расчёт: ARIMA(1, 1, 1) + сценарий предложения, горизонт 90 дн.]

Таким образом, прогноз цены Brent на горизонте 90 дней при сценарии сокращения предложения на 1.50 млн барр./сут составляет 105.71 долл./барр., а 95% доверительный интервал прогноза — 73.04 — 138.39 долл./барр. [Расчёт: ARIMA(1, 1, 1) + сценарий предложения, горизонт 90 дн.]
